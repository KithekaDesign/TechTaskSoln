help_outline How Escrow Works

1. You fund the escrow — ETH is locked in the smart contract, not sent to the freelancer yet.
2. Freelancer completes the work and marks the project done.
3. You review the work. If satisfied, you release funds directly to the freelancer's wallet.
4. If there's a dispute, an admin can resolve it via the smart contract.
